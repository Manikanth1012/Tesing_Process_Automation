📊 Project Hierarchy
4-level structure from Projects to Test Runs
Project (e.g., PAYGW) └── Test Plan (Sprint/Release) ├── Feature (API/Functional/GUI/Performance) │ ├── Prerequisites (checklist + readiness %) │ ├── Reference Templates (specs, contracts) │ └── Test Case │ ├── Steps (JSON structured) │ ├── Expected Result │ └── RF Script (.robot file) │ └── Test Run │ ├── Execution (per case) │ └── Defect (linked)
🔄 REACT Loop — All Agents
PERCEIVE
Gather context from DB, uploaded files, and user input
REASON
Analyze data and plan next action using Claude's reasoning
ACT
Execute tool calls (DB query, file parse, script generation)
REFLECT
Validate output, stream to UI, persist suggestions for human review
🎯 Key Principles
✓ All agent suggestions require explicit Accept/Reject/Modify
✓ Live SSE streaming for real-time thinking visibility
✓ Readiness gate: ≥70% for test gen, 100% for script gen
✓ Dry-run validation before script approval
✓ EXECUTION_MONITOR auto-triggers on run completion
