Database Persistence
Permanent storage in SQLite (tamt.db) · Stores all project data, agent runs, suggestions, and audit trail
Core Storage Tables
agent_runs
Complete audit log of all agent executions: agent_type, status, tokens_used, duration, error_message
agent_suggestions
Structured suggestions from agents awaiting human approval: test cases, scripts, defect drafts, analysis reports
test_cases
Generated test cases with structured steps (JSON), expected results, RF keyword hints, linked to features
robot_scripts
.robot file metadata + versions, dry-run validation results, approval status, content stored in filesystem
Agent Context Tables

Readiness checklist items with completion status. Read by PREREQ_ANALYST for scoring.
reference_templates
API specs, Swagger contracts, Functional TC templates. Context for TESTCASE_GENERATOR.
test_executions
Parsed output.xml results. Read by EXECUTION_MONITOR for health scoring.
defects
Triaged defects with severity, priority, steps. Created by DEFECT_TRIAGE agent.

Memory Recall Scenarios — How Context Surfaces Automatically
L1 — Conversational Context
User says: "Generate test cases for that feature"
L1 history[] has previous messages discussing "Login API feature"
Agent resolves "that feature" to Login API without asking user to repeat
L2 — Agent State Carry-Over
PREREQ_ANALYST runs and calculates readiness = 85%
Updates features.readiness_score in database
Next agent (TESTCASE_GENERATOR) reads same field to enforce ≥70% gate
L3 — Historical Agent Runs
User asks: "Show me all my previous test generations"
Query agent_runs table WHERE agent_type='TESTCASE_GENERATOR'
Returns full history: timestamps, tokens used, success/failure status
L3 — Suggestion Retrieval
SCRIPT_GENERATOR creates 3 .robot scripts for a feature
Each stored in agent_suggestions with status='Pending'
UI queries agent_suggestions to display for Accept/Reject/Modify
L3 — Execution Context
User clicks "Triage with AI" on failed test execution
DEFECT_TRIAGE reads test_executions.error_message + test_cases.steps
Full context injected into Claude prompt for accurate severity classification
L3 — Cross-Feature Learning
User generates scripts for similar API features across projects
SCRIPT_GENERATOR queries robot_scripts for patterns from other features
Reuses proven keyword structure, improving consistency across test suite
